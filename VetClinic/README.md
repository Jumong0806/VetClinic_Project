# Vet Kita - Veterinary Clinic Patient Record System

IT 203 - Object Oriented Programming | BSIT 2H-G2 | Bulacan State University

A Java 17 Swing application that keeps animal patient records and treatment history, so a vet can find an
animal's treatment history in seconds instead of searching index cards.

## Run it (no database needed)

1. Open this folder in IntelliJ (File > Open). Mark `src` as Sources Root. Use JDK 17 or newer.
2. Run `vetclinic.Main`. Records are saved to `data/animals.dat` and `data/staff.dat`.

## Switches in `Main.java`

- `USE_MYSQL = false`: set to `true` to use MySQL (bonus). See `db/schema.sql` and the connection guide in `VetClinic_SourceCode.md`.
- `ENABLE_PHASE_2 = false`: set to `true` to switch on the Phase 2 extras (notifications, advanced dashboard, filters, Save All).
